# four_robot_cell — fabricator4, a four-robot welding cell

Four UR10e on linear rails sharing one beam, modelled on the Voortman Fabricator: `robot1` is the handler (Robotiq 2F-85), `robot2`–`robot4` are MIG welders. The handler places each plate and **holds** it while a welder tacks it; the welders then run the fillet seams. Who welds what is decided by the pipeline. This is the cell `fabricator4` of the TAMP pipeline (`cell.yaml`); ROS package `four_robot_cell`.

| Path | Content |
| --- | --- |
| `urdf/fabricator4_layout.yaml` | where each robot stands: rail position, orientation, travel, tool |
| `urdf/fabricator4_cell.urdf.xacro`, `config/` | URDF, SRDF, MoveIt and `ros2_control` files, built from the layout |
| `scenes/tamp_task_fabricator.yaml` | the welding job: 6 plates, a pick-place with hold, a tack and fillet seams per plate |
| `vamp_modules/ur10e_rail_torch/` | the welder's sphere model for VAMP (the handler uses `dual_robot_cell`'s `ur10e_rail`) |

The UR macros come from `multi_robot_cell_description`. The scene and the layout are generated by `thesis_material_tamp/tools/make_fabricator.py` and `fabricator_layout.py`: edit and re-run those scripts, not the numbers in the YAML.

## Run

```bash
ros2 launch multi_robot_cell_tamp pipeline.launch.py task:=fabricator refine:=false save_as:=fab
ros2 launch multi_robot_cell_bringup start.launch.py cell:=fabricator4                   # terminal 1
ros2 launch multi_robot_cell_tamp execute_schedule.launch.py mode:=tpg run:=fab          # terminal 2
```

- `refine:=false` is required: commute refinement handles two robots only, and the pipeline stops with an error otherwise.
- The bringup lives in `dual_robot_cell/multi_robot_cell_bringup` (argument `cell:=fabricator4`).
- During execution the welds are emulated: each welder publishes `/<robot>/process_active` while its arc is on, and RViz shows the seams on `/weld_seams` (`process_events:=false` turns this off).

A smaller test scene, `scenes/tamp_task_holdprobe.yaml` (one plate, one hold, one seam), runs with `task:=holdprobe refine:=false`.
